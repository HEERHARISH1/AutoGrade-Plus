QUESTION:
Write a Python function called `factorial` that calculates the factorial of a given number n.
The function should handle edge cases (n=0, n=1) and use recursion.

RUBRIC:
1. Correctness (5 points): Function returns correct factorial values
2. Edge Cases (3 points): Handles n=0 and n=1 correctly
3. Recursion (2 points): Uses recursive approach

STUDENT ANSWER:
Student ID: i222371

def factorial(n):
    """
    Calculate factorial of n using recursion.
    
    Args:
        n: Non-negative integer
        
    Returns:
        Factorial of n
    """
    # Handle edge cases
    if n == 0 or n == 1:
        return 1
    
    # Recursive case
    return n * factorial(n - 1)

# Test cases
print(factorial(0))  # Output: 1
print(factorial(1))  # Output: 1
print(factorial(5))  # Output: 120
